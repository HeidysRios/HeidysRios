### Proyectos Destacados

* **Descripción:** Prototipo interactivo en Figma para la reserva de citas y gestión de agendas entre clientes y emprendedores locales.
* **Stack:** Figma, Metodología UCD, Prototipado Interactivo.

#### 2. [Dojo Pay Control - Sistema de Cobros](https://github.com/HeidysRios/Dojo-Pay-Control)

* **Stack:** C#, .NET 8, Windows Forms, JSON.
* **Rol:** Diseño visual del tablero interactivo (7x6), menú de juego y aplicación de principios de POO.
